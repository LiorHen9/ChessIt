# בדיקות בטלפונים אמיתיים

רשימה לבדיקה ידנית לפני שמשתפים את הקישור. את רוב הדברים הבדיקות האוטומטיות כבר בודקות בדפדפן מחשב בגודל טלפון, אבל יש דברים שרק טלפון אמיתי מראה: קול, מתג שקט, מצלמה, וואטסאפ, רשת סלולרית, ו-Safari של אייפון.

**איך עובדים עם הרשימה**: עדיף שני טלפונים – אנדרואיד אחד ואייפון אחד. בכל שורה עושים את מה שבעמודה "מה עושים", ומסמנים ✓ אם קרה מה שבעמודה "מה אמור לקרות", או ✗ ומשפט קצר על מה שקרה. כל ✗ – לשלוח לי (עם הפרטים מ**הגדרות ← 🐞 מצאת בעיה? ← העתקת הפרטים**), ולרשום בטבלת הבטא ב-[ROADMAP.md](ROADMAP.md).

לפני שמתחילים: אם האפליקציה כבר מותקנת, לסגור אותה לגמרי ולפתוח מחדש, כדי לקבל את הגרסה החדשה. במסך **הגדרות ← ℹ️ אודות ופרטיות** רואים את מספר הגרסה (צריך להיות `0.9.0` או חדש יותר).

## 7. נגישות בסיסית

**VoiceOver באייפון**: הגדרות ← נגישות ← VoiceOver ← הפעלה. מחליקים ימינה ושמאלה כדי לעבור בין פריטים, הקשה כפולה ללחיצה. (לכיבוי: אותו מקום, או "היי סירי, כבי VoiceOver".)
**TalkBack באנדרואיד**: הגדרות ← נגישות ← TalkBack ← הפעלה. אותן תנועות.
